🥤 DevEllen Refri – Landing Page Animada

🔗 Link do projeto:  https://dinaellencutrim3.github.io/DevEllen-refriAnima-o/

Este projeto é uma landing page animada de refrigerantes, desenvolvida com foco em design moderno, animações suaves e responsividade, simulando uma vitrine de produto para web.

A proposta visual destaca o produto principal (lata de refrigerante) com frutas em grande escala envolvendo o nome e o produto, criando um efeito imersivo e profissional.

✨ Funcionalidades

🎞️ Carrossel de sabores com navegação por botões

🍓 Frutas cenográficas envolvendo o nome e a lata

🥤 Produto central em destaque

🎨 Fundo dinâmico por sabor

📱 Layout responsivo (desktop, notebook e mobile)

⚡ Animações suaves de baixo para cima

🧩 Organização por camadas (z-index)

🛠️ Tecnologias Utilizadas

HTML5 – Estrutura semântica

CSS3 – Layout, animações e responsividade

JavaScript – Controle do carrossel

📐 Conceito de Design

O layout foi pensado em camadas:

Fruta: elemento visual de ambientação, envolvendo o nome e o produto

Lata: foco principal da página

Título: legível e centralizado

Animações: suaves, utilizando transform e opacity para melhor performance

O uso de clamp() garante que os elementos se adaptem automaticamente a diferentes tamanhos de tela.

📱 Responsividade

O projeto foi ajustado para:

🖥️ Desktop

💻 Notebook

📱 Mobile

Utilizando media queries para manter harmonia visual e usabilidade em todos os dispositivos.
